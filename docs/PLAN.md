# egg_Edit 설계 문서

PC, 웹, 스마트폰에서 글·그림·파일·음악을 모두 동기화하는 나만의 저장소(personal repository).

## 기능

1. **문서 편집**: 글 작성, 수정, 삭제
2. **이미지 편집**: 그림 그리기, 수정, 편집
3. **폴더 관리**: 중요한 파일을 폴더 형태로 저장, 삭제
4. **음악 관리**: 음악 파일 저장, 링크 걸어 두기
5. **백업 / 복원**: 모든 구조와 데이터를 ZIP 하나로 내려받고, 언제든 다시 올리기

## 기술 구조

| 영역 | 선택 | 이유 |
|---|---|---|
| 화면 | React + TypeScript (Vite) | 코드 하나로 웹·PC·폰을 모두 지원 |
| PC 앱 | Tauri | 웹 앱을 가볍게 감싸 Windows/Mac 설치형 앱으로 |
| 폰 앱 | Capacitor | 웹 앱을 Android/iPhone 앱으로 |
| 동기화 서버 | Supabase | 로그인, DB(PostgreSQL), 파일 저장소, 실시간 동기화 |
| 문서 편집기 | TipTap | 워드처럼 쓰는 편집기, 내용을 JSON 으로 저장 |
| 그림 편집 | Konva | 캔버스 위에 그리기/편집, 편집 상태를 JSON 으로 저장 |

## 데이터 구조

자세한 정의는 [`supabase/migrations/0001_init.sql`](../supabase/migrations/0001_init.sql).

- `folders`: 폴더 트리 (`parent_id` 로 상위 폴더)
- `items`: 모든 콘텐츠. `kind` 가 `document` / `image` / `file` / `music`
  - 글 내용, 그림 편집 데이터, 음악 링크 → `content` (JSON)
    - 문서는 `doc`(편집기 JSON), `html`(앱 없이 열리는 사본), `text`(검색용), `tags`, `attachments`(문서 속 이미지 경로)를 함께 저장
    - 문서 속 이미지는 Storage `<user_id>/<문서 id>/img-….png` 에 두고, 문서에는 `vault://<경로>` 로 기록 (열 때 잠깐 쓰는 주소로 바꿈)
  - 실제 파일(그림 PNG, 첨부, 음악 파일) → Storage 버킷 `vault` 의 `<user_id>/<item_id>/<파일명>`
- 모든 테이블에 Row Level Security: 자기 데이터만 읽고 쓸 수 있다.

## Supabase 에 묶이지 않기 위한 원칙

Supabase 가 사라지거나 바꾸고 싶어져도 데이터와 구조를 잃지 않도록:

1. **백업 기능 내장**: 앱 안에서 언제든 [백업 내려받기] → ZIP 파일.
   - 앱 없이도 열어 볼 수 있는 형식: `README.txt`, `manifest.json`, `data/*.json`, `files/…`,
     `documents/…` (문서를 폴더 구조 그대로 HTML 로. 더블클릭하면 브라우저로 읽힘)
   - [백업 복원] 으로 같은 서버든 새 서버든 그대로 되살린다. (소유자 id 와 파일 경로는 자동으로 바꿔 줌)
   - 백업 형식에는 버전 번호가 있어서, 앱이 바뀌어도 옛 백업을 읽을 수 있게 유지한다.
2. **백엔드 분리**: 화면 코드는 `VaultBackend` 인터페이스(`src/data/types.ts`)만 사용한다.
   Supabase 에 의존하는 코드는 `src/data/supabaseBackend.ts` 에 모은다.
   다른 서버로 옮길 때는 이 파일 하나를 새로 구현하면 된다.
3. **표준 기술만 사용**: DB 는 일반 PostgreSQL 기능만 쓴다. 필요하면 `pg_dump` 로 DB 전체를 통째로 옮길 수도 있다.
4. **구조도 저장소에**: DB 구조(SQL)는 이 git 저장소에 있으므로, 새 서버에 그대로 다시 만들 수 있다.

## 만드는 순서

- [x] **0단계 – 기초**: 프로젝트 뼈대, DB 구조, 로그인, 백업/복원
- [x] **1단계 – 폴더 관리**: 폴더 만들기/이름 바꾸기/삭제, 파일 올리기(끌어다 놓기 포함)/내려받기/이름 바꾸기/삭제, 실시간 동기화
- [x] **2단계 – 문서 편집**: 서식 편집기(제목, 굵게, 글머리 기호/번호 모양 선택, 체크리스트, 인용, 코드, 링크, 글자 색·형광펜 색, 이미지 넣기(버튼/붙여 넣기/끌어다 놓기, 크기 조절), 표), 자동 저장, 문서 목록과 검색, 다른 기기 수정 알림, 백업에 HTML 사본
- [x] **3단계 – 음악 관리**: 음악 파일 올리기(버튼/끌어다 놓기, 가수·제목·길이 자동), 링크(YouTube·Spotify·SoundCloud 는 앱 안에서 재생, 멜론 등은 새 탭), 즐겨찾기, 거르기/검색, 정보 고치기, 화면을 옮겨도 계속되는 재생기(섞기/반복/잠금 화면 조작), 백업에 음악 목록 HTML
- [ ] **4단계 – 이미지 편집**
- [ ] **5단계 – 실시간 동기화 마무리, PC 앱(Tauri), 폰 앱(Capacitor)**
- [ ] 이후: 폴더/파일 옮기기, 검색, 오프라인에서도 쓰고 나중에 동기화, 자동 정기 백업
